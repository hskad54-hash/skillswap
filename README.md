# Skill Swap - Campus Skill Exchange Platform

A peer-to-peer campus web application designed to connect students with complementary skills. Students can offer their expertise (coding, design, video editing, music, languages) in exchange for learning new skills or finding project collaborators.

---

## 🚀 Features

* **Skill Matchmaking Engine**: Discover students willing to teach skills you want to learn or collaborate on projects.
* **Dual Profiles (Teach & Learn)**: Set up customized profiles listing "Skills I Can Teach" and "Skills I Want to Learn".
* **Skill Request & Exchange System**: Send direct exchange requests or collaboration invites to fellow students.
* **Filter & Search**: Search campus peers by specific skill categories, project interests, and availability.
* **Collaborator Directory**: Find teammates for hackathons, side projects, and campus competitions.
* **Fully Responsive**: Sleek, intuitive interface built with React and Tailwind CSS for mobile and desktop screens.
